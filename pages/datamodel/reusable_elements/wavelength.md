# Wavelength

## value 
**Description**: Numerical value of the wavelength <br/>
**Required**: yes <br/>
**Type**: number (float) <br/>
**Minimum**: 0

## unit 

**Description**: The unit of the wavelength <br/>
**Required**: yes <br/>
**Type**: enumerator (string) <br/>
**Options**: ('Å', 'nm', 'μm', 'mm', 'cm', 'm')
